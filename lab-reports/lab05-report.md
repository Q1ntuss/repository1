# Лабораторна робота №5: Розробка RESTful API

## Інформація про проєкт
- **Назва проєкту:** Інтернет-магазин на Flask
- **Автори:** Семенов Владислав, Бондарук Владислав, Остапчук Богдан, Сасін Павло, Жук Максим

## Опис проєкту
Проєкт реалізує простий RESTful API для інтернет-магазину. Користувачі можуть переглядати товари, додавати їх до кошика, оформлювати замовлення та залишати відгуки. Адміністратор може додавати, редагувати та видаляти товари, а також переглядати замовлення.

## Технології
- Python 3.14
- Flask
- SQLite
- Jinja2
- Tailwind CSS

## Endpoints API

### 1. Перегляд товарів
- **URL:** `/shop`
- **Метод:** `GET`
- **Опис:** Повертає список усіх товарів у магазині.
- **Приклад відповіді:**
```json
[
  {
    "id": 1,
    "name": "Ноутбук",
    "description": "Ігровий ноутбук",
    "price": 32432.0,
    "stock": 5
  }
]
