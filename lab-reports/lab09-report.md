## Опис проєкту та його призначення

Цей вебзастосунок — це інтернет-магазин, створений для зручної покупки товарів, отримання відгуків користувачів, оформлення замовлень та можливості швидкого зворотного зв’язку.
Основна ідея проєкту — розробити доступний, простий та корисний інструмент, який може стати основою для повноцінного онлайн-магазину та бути корисним для людей у повсякденному житті.

## Використані технології та обґрунтування вибору

Python — основна мова бекенду, гнучка, проста у підтримці та зручна для швидкої розробки.

SQLite — легка вбудована база даних, зручна для навчальних і невеликих проєктів.

HTML — базові стилі та шаблони для фронтенду, забезпечують простий інтерфейс.

Docker — використовується для контейнеризації та зручного розгортання застосунку, робить процес запуску стабільним і незалежним від системи.

## Архітектура системи

 Архітектура складається з трьох основних частин:

Frontend
HTML-сторінки з базовими стилями та логікою взаємодії з користувачем.

Backend
Серверна частина написана на Python, відповідає за:

обробку запитів,

управління товарами,

роботу з кошиком,

зворотний зв’язок.

Database (SQLite)
Використовується для зберігання:

товарів,

замовлень,

відгуків,

даних для адмін-панелі.

 Взаємодія між частинами відбувається через стандартні HTTP-запити.

## Виправлені помилки

Виникали помилки, пов’язані з базою даних (SQLite),
наприклад:

неправильні зв’язки,

відсутність таблиць,

некоректні шляхи до БД.

Усі ці помилки були виправлені шляхом ручної корекції моделі даних та повторного запуску міграцій.

## Технічні виклики та способи їх вирішення
