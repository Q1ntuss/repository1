    ## 🔌 API Endpoints

    Опишіть які ендпоінти використовуються: 
GET /items — отримує список усіх об'єктів.
GET /items/{id} — отримує детальні дані про один об'єкт за ID.
POST /items — створює новий об'єкт у системі.
PUT /items/{id} — повністю замінює існуючий об'єкт новими даними.
PATCH /items/{id} — частково оновлює лише окремі поля об'єкта.
DELETE /items/{id} — видаляє об'єкт із бази даних.
POST /login — виконує вхід користувача та видає токен доступу.
GET /me — повертає профіль поточного авторизованого користувача.
GET /health — перевіряє, чи працює сервер у штатному режимі.

    ### GET /api/your-endpoint
    Отримує список всіх записів.

    **Відповідь:**
    ```json
    [
      {
        "id": 1,
        "field1": "значення",
        "field2": "значення"
      }
    ]
    ```

    ### POST /api/your-endpoint
    Створює новий запис.

    **Тіло запиту:**
    ```json
    {
      "field1": "значення",
      "field2": "значення"
    }
    ```
