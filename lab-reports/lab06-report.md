    ## 📋 Опис проєкту

    Цей вебзастосунок на Flask дозволяє користувачу переглядати список ресурсів (товарів), 
    що зберігаються на сервері через API, додавати нові записи через веб-форму та бачити повідомлення про успіх або помилки


    ## 📁 Структура проєкту

    ```
    project/
    ├── index.html       # Головна сторінка
    ├── style.css        # Стилі
    ├── script.js        # JavaScript логіка
    ├── README.md        # Цей файл
    └── backend/         # Flask API (з лаб. роботи 5)
        ├── app.py
        └── ...
    ```

    ## 🔌 API Endpoints

    Опишіть які ендпоінти використовуються:

    ### GET /api/your-endpoint
    Отримує список всіх записів.

    **Відповідь:**
    ```json
    [
      {
        "id": 1,
        "field1": "значення",
        "field2": "значення"
      }
    ]
    ```

    ### POST /api/your-endpoint
    Створює новий запис.

    **Тіло запиту:**
    ```json
    {
      "field1": "значення",
      "field2": "значення"
    }
    ```
